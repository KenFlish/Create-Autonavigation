# Create: Autonavigation Publishing Text

## Short Description

Create: Autonavigation is a compact addon for Create: Aeronautics that adds a smart navigation table with built-in coordinate targeting, so you can steer ships and vehicles without magnetite or manual compass setup.

## Full Description

Create: Autonavigation is a lightweight addon for Create and Create: Aeronautics.

It introduces the Smart Navigation Table, an upgraded version of the navigation table designed for easier and more flexible autopilot control. Instead of manually preparing a compass and relying on magnetite, you can enter target coordinates directly in the table's built-in GUI and guide your craft more comfortably.

This makes navigation much smoother for flying, driving, and sailing machines built around Create: Aeronautics. The mod keeps the familiar idea of the original navigation table while extending it with direct coordinate input for faster route setup and better mobility.

## Examples of Using the Smart Navigation Table

You can build military auto-guiding contraptions, equip your airships and airplanes with easier autopilot targeting, and prepare better coordinate-driven navigation systems for large moving vehicles.

It works especially well on mobile Aeronautics builds where you want to retarget quickly without stopping to prepare a compass or rely on magnetite placement.

The result is a more practical navigation workflow for combat vehicles, transport craft, scouting machines, and large ships that need fast and repeatable route control.

Current features:

- Smart Navigation Table with built-in coordinate input
- No magnetite requirement
- No manual compass setup
- More convenient autopilot targeting for Aeronautics vehicles
