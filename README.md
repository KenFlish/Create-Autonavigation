# Create: Autonavigation for NeoForge 1.21.1

https://modrinth.com/mod/create-autonavigation https://www.curseforge.com/minecraft/mc-mods/create-autonavigation/preview

Overview:
Create: Autonavigation is a lightweight addon for Create and Create: Aeronautics. It introduces the Smart Navigation Table, an upgraded version of the navigation table designed for easier and more flexible autopilot control. Instead of manually preparing a compass and relying on magnetite, you can enter target coordinates directly in the table's built-in GUI and guide your craft more comfortably.

This makes navigation much smoother for flying, driving, and sailing machines built around Create: Aeronautics. The mod keeps the familiar idea of the original navigation table while extending it with direct coordinate input for faster route setup and better mobility. Current features: Smart Navigation Table with built-in coordinate input, no magnetite requirement, no manual compass setup, and more convenient autopilot targeting for Aeronautics vehicles.
