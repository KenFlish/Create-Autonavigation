# Create: Autonavigation for NeoForge 1.21.1

This project is based on the official NeoForge MDK for Minecraft `1.21.1`.

Included:

- `create_autonavigation` as the technical mod id
- `Create: Autonavigation` as the display name
- one custom creative tab: `Create: Autonavigation`
- a clean package: `ru.codex.kenmod`

Run commands:

```powershell
.\gradlew.bat runClient
.\gradlew.bat build
```

Current status:

- the template is downloaded
- dependencies are already resolved locally
- the project is ready for adding real content
